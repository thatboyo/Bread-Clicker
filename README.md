# Bread-Clicker

This project was made as part of HackClub Terra, 
It is NOT vibe-coded, the colors choosen for the colorscheme are the only thing AI, and that's because I am bad at color theory. The code writing is pretty much entirely my own.
(during this change I did look up how to use and load to and from local storage, my js knowledge is decently basic lol)


This is bread clicker, my own twist on cookie clicker. This was a lot of fun to make! You basically click the bread to get 1 bread per click, and then you use that bread to buy things to help you make bread automatically. Your goal is the buy the amazon company! Chungie gives 1 bread per second,  toaster gives 10 bread per second, bakery gives 20 bread per second, robot gives 60 bread per second, crafting table gives 250 bread per second, villager gives 1,000 bread per second, command block gives 6,400 bread per second, magic bread machine gives 120,000 bread per second, and once you buy the Amazon company you get 999,999 bread per second.
 

 THIS is a **WIP**, and I will be making many improvements to this project in order to turn it into a really fun game thats actually worth playing!
