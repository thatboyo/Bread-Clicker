# Bread-Clicker
like cookie clicker, but cooler and with bread and my own twist to it.
This is bread clicker, my own twist on cookie clicker. This was a lot of fun to make! You basically click the bread to get 1 bread per click, and then you use that bread to buy things to help you make bread automatically. Chungie gives 1 bread per second,  toaster gives 10 bread per second, bakery gives 20 bread per second, robot gives 60 bread per second, crafting table gives 150 bread per second,
 

 THIS is a **WIP**, and I will be making many improvements to this project in order to turn it into a really fun game thats actually worth playing!
